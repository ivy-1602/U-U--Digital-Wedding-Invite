There's a peacock drawn entirely in SVG markup sitting between sections because I thought it would be nice and then couldn't stop until it had eye-spots and a crown.

## What I built

A fully static site — HTML, CSS, and vanilla JavaScript, no frameworks, no build tools. Every animation is hand-written. Every ornament is inline SVG. The background colour shifts as you scroll through each section, interpolating between crimson and saffron and royal blue and sage green and blush pink. The body background is essentially a mood ring for the wedding schedule.

The music is *Sukh Kalale* on piano. It starts when you tap the splash screen.
